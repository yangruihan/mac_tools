# Mac 工具箱

原生 SwiftUI macOS 13+ 工具箱，首个模块是亮度与音频快捷控制。

## 构建与运行

```sh
swift test
./scripts/build-app.sh
open build/MacTools.app
```

在亮度或音频列表点击“添加配置”，编辑名称、百分比及修饰键和按键。配置自动保存；更改滑块不会改变实际设备，点击“应用”或触发已注册快捷键才会执行。空按键表示不启用快捷键。冲突会显示在对应配置下。菜单栏也可以应用配置或重开窗口。

默认耳机保护将所有音量写入限制在 18%；关闭需要确认，重启恢复开启。百分比不等同于声压或听力安全保证。应用不会自动取消静音，不会在启动时应用配置。

亮度首版支持内置屏幕，通过系统非公开 DisplayServices 接口执行，不适合直接承诺 App Store 发布；外接屏未实现。音频使用默认输出设备的系统主音量接口，不支持的软件音量设备会显示错误，不偷偷切换输出设备。

构建产物位于 build/MacTools.app，当前为本机架构、临时签名，未做 Developer ID 签名和公证。退出通过菜单栏“退出”或 Command-Q。

## 菜单栏驻留

启动后只显示菜单栏图标，不自动弹出主界面，也不占用 Dock。点击菜单栏“打开工具箱”显示配置窗口；关闭窗口不会退出应用，快捷键继续生效。再次打开复用同一窗口。菜单同时显示耳机保护状态；彻底退出请用菜单中的“退出”。

## 显示 / 收起快捷键（更新）

启动时显示配置界面；关闭窗口仍保留菜单栏，不退出。窗口顶部可配置全局“显示界面 / 收起到托盘”快捷键，默认 Command+Option+M，修改自动保存；与亮度/音量快捷键共用冲突检测。界面在前台时按下收起；隐藏、最小化或在其他应用后面时按下显示并激活。也可点击“收起到托盘”按钮。再次启动应用可重新打开界面。本节替代上一版“启动不弹出界面”的行为。

## 配置锁定

每项配置可勾选“锁定”，点击应用或触发该配置快捷键后生效。亮度、音量独立：成功应用同类未锁定配置才解除对应锁定；切换失败不解除。修改勾选、编辑或删除配置不改变已生效锁定；新增并应用未锁定配置也可解除。

锁定在应用运行期间每约 200ms 读取并恢复数值，不是系统权限级拦截：系统滑块可能短暂变化，音频可能短暂变响，不能作为听力安全机制。音频只锁定默认输出设备的音量百分比，不拦截静音或设备物理旋钮；更换默认输出后会尝试维持相同百分比，不支持的设备会报错。退出应用后不再维持，重启不自动应用任何配置。开启耳机保护时锁定值不超过 18%。

## 保持唤醒

主界面和菜单栏均有“保持唤醒”开关，共享同一状态，默认关闭且不跨重启保存。开启后使用 macOS IOKit 电源断言防止闲置熄屏、闲置休眠；关闭窗口不影响，关闭开关或退出应用释放请求。不会更改系统设置或亮度、音量配置。

这不是禁用密码或强制解锁：屏保锁屏、手动锁屏、合盖、管理员策略不在保证范围内。请勿把它当作绝对防锁屏功能；开启会增加耗电。
