# Mac 工具箱

原生 SwiftUI macOS 13+ 工具箱，采用可独立启停的**内置 Swift 插件**组织功能，无第三方运行时依赖。

## 构建与运行

```sh
swift test
./scripts/build-app.sh
open build/MacTools.app
```

## 内置插件

| 插件 | 功能 | 停用时 |
| --- | --- | --- |
| 快捷控制 | 亮度/音量配置、按钮应用、全局快捷键、锁定、耳机保护、一键解锁 | 解除锁定并注销该插件快捷键；不改变设备数值 |
| 保持唤醒 | 防闲置熄屏和休眠 | 释放电源断言 |
| 屏蔽内置触控板 | 操作系统“有外接鼠标时忽略内建触控板”开关 | 恢复原系统开关；失败时保留启用并报告 |

右上角和菜单栏的“插件”菜单控制工具是否可用。插件内部开关控制对应功能是否生效，二者不同。停用不会删除配置；工具卡片按注册信息自动显示，新增工具不需要给主界面增加类型分支。

开发入口：[插件架构与扩展指南](docs/PLUGINS.md)。当前插件编译进应用，不是网络安装或动态加载第三方二进制的机制。

## 快捷控制

在亮度或音频列表点击“添加配置”，编辑名称、百分比及修饰键和按键。配置自动保存；更改滑块不会改变实际设备，点击“应用”或触发已注册快捷键才执行。空按键表示不启用快捷键；系统或其他插件占用时显示错误。

“解除所有锁定”及其快捷键设置位于快捷控制插件中，菜单栏也可解锁。不改变当前数值、不修改配置里的“锁定”勾选；下次应用锁定配置可重新锁定。

- **音量保护**：默认上限 18%，关闭需要确认，重启恢复开启。百分比不等同于声压或听力安全保证。应用不自动取消静音，也不在启动时应用配置。
- **锁定**：每约 200ms 读取并恢复数值，非系统级拦截，变化可能短暂生效。亮度与音量独立；成功应用同类未锁定配置，或点“解除所有锁定”，或停用插件可解除。编辑/删除配置本身不解除已有锁定。
- **亮度边界**：仅内置屏幕，使用非公开 DisplayServices 接口；外接屏未实现，不能承诺 App Store 上架。0% 可能使屏幕变黑。
- **音频边界**：默认输出设备的软件主音量，不拦截静音或物理旋钮；不支持的软件音量设备明确报错，不偷偷切换输出设备。

## 保持唤醒与触控板

保持唤醒使用 IOKit 电源断言，不永久修改系统设置。默认关闭，不跨重启恢复；关闭窗口不影响。屏保锁屏、手动锁屏、合盖或管理员策略不在保证范围内，不应当作绝对防锁屏功能。

触控板工具直接操作“系统设置 → 辅助功能 → 指针控制”的真实开关，首次需为 Mac 工具箱授予辅助功能权限。仅在系统识别到外接鼠标或无线触控板时生效。正常关闭/退出时尝试恢复原开关；崩溃、强制结束或权限被撤销时可能需要手动恢复。系统版本和非 Apple 鼠标驱动仍可能影响兼容性。

## 宿主界面

- 启动显示窗口；关闭窗口仍驻留菜单栏，不占 Dock。点击“打开工具箱”或窗口快捷键可重开。
- “窗口快捷键”控制显示/收起，默认 Command+Option+M，修改后保存；插件自己的快捷键在插件内设置。
- “外观”提供跟随系统、浅色、深色，立即生效并保存，只影响本应用。
- 默认窗口内容区 980×740，最小 900×640，原生系统配色；工具内容放在可扩展滚动区。
- 旧配置自动复制到插件命名空间，旧 key 保留不覆盖；降级会读取迁移时的旧版本数据，详见扩展指南。
