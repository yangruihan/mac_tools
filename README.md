# Mac 工具箱

原生 SwiftUI macOS 13+ 工具箱，首个模块是亮度与音频快捷控制。

## 构建与运行

```sh
swift test
./scripts/build-app.sh
open build/MacTools.app
```

在亮度或音频列表点击“添加配置”，编辑名称、百分比及修饰键和按键。配置自动保存；更改滑块不会改变实际设备，点击“应用”或触发已注册快捷键才会执行。空按键表示不启用快捷键。冲突会显示在对应配置下。菜单栏也可以应用配置或重开窗口。

默认耳机保护将所有音量写入限制在 18%；关闭需要确认，重启恢复开启。百分比不等同于声压或听力安全保证。应用不会自动取消静音，不会在启动时应用配置。

亮度首版支持内置屏幕，通过系统非公开 DisplayServices 接口执行，不适合直接承诺 App Store 发布；外接屏未实现。音频使用默认输出设备的系统主音量接口，不支持的软件音量设备会显示错误，不偷偷切换输出设备。

构建产物位于 build/MacTools.app，当前为本机架构、临时签名，未做 Developer ID 签名和公证。退出通过菜单栏“退出”或 Command-Q。

## 菜单栏驻留

启动后只显示菜单栏图标，不自动弹出主界面，也不占用 Dock。点击菜单栏“打开工具箱”显示配置窗口；关闭窗口不会退出应用，快捷键继续生效。再次打开复用同一窗口。菜单同时显示耳机保护状态；彻底退出请用菜单中的“退出”。
