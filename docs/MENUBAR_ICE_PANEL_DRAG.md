# 缩略图面板内拖放（build13）
入口：菜单栏收纳 -> 高级·图标面板 -> 打开/关闭图标面板，或选择普通点击“图标面板”。
直接拖缩略图，不必按Command。同分区拖到目标图标左右半边换序；跨分区改变收纳归属。
放开后保存真实菜单栏位置，再重新采集。拖放不打开原应用、不执行15秒自动归位；普通点击仍走原打开流程。
过期截图、未知图标、身份/桌面变化或待恢复记录会拒绝；不会按新PID重匹配，不自动重投移动。
单屏普通桌面实测：自建N/T同区换序、收纳->常驻、常驻->收纳，各6投递、placed位置证据、清记录，均由助手CUA实际拖拽。
没有把第三方图标、应用重启保持、空分区或全屏/多屏扩展说成已验收。
回滚：先退出MacTools和组件，然后证据目录ROLLBACK.sh --panel-drag-installed-app /Applications/MacTools.app，恢复build9且保留当前副本。
