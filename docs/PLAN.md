# Mac 工具箱：快捷控制

1. 初始化：SwiftUI 原生 macOS 13+ 应用，无第三方依赖。
2. 实现：亮度/音量配置列表，添加、编辑、删除、本地保存、立即应用、Carbon 全局快捷键；菜单栏常驻。
3. 验证交付：构建 .app，离线自测配置校验与音量保护，不自动改变真实音量或亮度。

音频默认保护上限 18%，所有按钮和快捷键共用保护；用户可主动关闭保护。
亮度首版控制内置显示器，使用系统 DisplayServices 动态接口（非公开 API，不承诺 App Store 上架）；外接屏 DDC 不在本阶段。
音量控制默认输出设备；不支持系统音量的 HDMI/USB 设备明确报错。
快捷键使用 Command/Option/Control/Shift 加字母或数字，冲突显示错误，不请求辅助功能权限。
