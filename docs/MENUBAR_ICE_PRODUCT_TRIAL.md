# MacTools Ice 产品候选：本机自建 T/N 试用

2026-10-08。候选应用：[MacTools Ice Candidate.app](../build/MacTools%20Ice%20Candidate.app)。它是已有MacTools产品页到已签名Ice工作端的受限接入，当前支持本机单屏、自建T/N。普通应用图标的自动搬移尚未接入；正式 `/Applications/MacTools.app` 0.2.0(4)及正式backend未改。

## 使用

1. 打开 `build/MacTools Ice Candidate.app`，默认选中菜单栏收纳页。
2. 点“打开 T/N 测试窗口”。该动作先核验来源、签名组件与恢复状态，再创建唯一新会话；仅准备和打开窗口，尚不发送鼠标事件。
3. 在控制窗口点“开始自建 T 单轮”。按Ice鼠标活动策略搬出T、打开菜单、自有关闭请求关闭菜单、等待15秒后归位。需要停止时点控制窗口“取消本轮”。产品页“检查结果”显示实际终态，“查看证据”打开本轮目录。

运行会影响焦点和光标。关闭产品窗口不代表取消独立工作端；使用控制窗口取消。每个产品页实例只准备一轮，不重复Start；再次测试前确保原控制窗口和fixture已结束、无待恢复记录。未确认down或写入未知继续保留责任，不补发、不隐式清除。

候选有独立Bundle ID `com.ryanai.mactools.icecandidate`及独立设置，不恢复正式收纳开关、不注册正式快捷键、不自动操作普通应用图标。正常入口不使用严格ANY授权；旧ANY路径仍仅诊断，旧失败不算成功。
