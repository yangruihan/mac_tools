## 已落到代码的行为

- MenuBarIconIdentity.identify 分离身份与可见性：同一进程启动中的精确窗口即使被长分隔符停放在屏外也可核实；重启只允许同 bundle／路径的唯一项重匹配。多项歧义仍拒绝猜测。原 resolve 的安全像素点击校验保持不变。

### 本次确定复现的 JSON 故障机制及修复

按钮屏幕框与 CG 窗口框没有交集时，CGRect.intersection 得到 CGRect.null，其 minX／minY 为无限值。**本机 Foundation 的 JSONSerialization.data 对这种值抛出 Objective-C NSInvalidArgumentException，而不是 Swift Error**，具体原因为 Invalid number value (infinite) in JSON write。因此原来的 try? 或 do/catch 无法记录该异常，不能把“没有 ui-state-error.txt”当作没有写入异常。

新增离线子进程检查实际复现该异常及 SIGABRT(6)。修复后的共享状态编码先用 isValidJSONObject 拒绝整个非法状态，让错误成为可捕获的 Swift Error；几何编码拒绝 null／infinite／empty／NaN，按钮不可用时仅发布 buttonGeometryUnavailable，不发布伪坐标；无效窗口框不发布目标。有限有效框保留原数值。四类无效几何、整份状态拒绝及有效状态序列化均通过。
