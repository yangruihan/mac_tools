## 上游路径及实际保留行为

窗口读取沿用已批准的六个CGS只读符号，核对菜单栏窗口成员、status layer、PID、正尺寸frame和当前Space；隐藏项不会因为屏外就被丢弃。事件源为hidSystemState，userData递增，设置targetPID和三个窗口字段（包括0x33）；move的down带Command，up不带。move通过主动PID null tap和session listenOnly tap执行 **null→PID，真实事件→session，再→PID**；匹配上游四字段，50ms有界等回执，并等目标frame改变。click只走session down/up，clickState=1。正常操作包含permit-all/零suppression配置、隐藏/归回/显示光标。普通失败保留fallback up、wake up及最多五次搬移。临时显示等待15秒，按钮按住或自有菜单还在时延后3秒；归位失败也按3秒延后重试，但受到候选全局预算限制。

独立候选采用Ice的100ms mouseMoved静止策略；生产ANY没有接入或改变。主动PID null tap会丢弃其监听到的null事件，包括未匹配marker的null，保持上游行为；该能力只能出现在此次已授权独立候选中。

## 与完整 Ice 产品的差异

| 项目 | 本候选的明确差异 |
| --- | --- |
| 场景和布局 | 仅同一自建进程的T/H/N；H为自有宽分隔项，初始T–H–N。搬到N右侧，回到H左侧。没有Ice Bar截图、任意应用缓存、第三方菜单处理或完整布局编辑器 |
| 目标识别 | 对自建窗口加nonce、路径、签名、启动时间、源码清单、SHA及新鲜状态绑定；读不到frame拒绝，不采用上游读不到frame后的固定等待降级 |
| 显示空间 | 限本机15.7.4及主显示器刘海右侧正尺寸可见区域。必须N可见且留足T宽度；不猜坐标、不搬第三方来腾空间。初始不满足时零投递拒绝 |
| 输入观察 | NSEvent本地/全局mouseMoved监测；归位时用pressedMouseButtons快照。完整Ice使用UniversalEventMonitor和eventTracking模式监测鼠标按下/释放；本候选没有复刻其整个监测框架，也不声称观察全部物理输入 |
| 时限与取消 | 45秒总期限、最多200次route投递，50ms局部截止在callback与投递前检查。显式取消、身份/权限失效、预算耗尽永久停止后续fallback、wake、归位及旧光标回拉；光标可见性仍配平。关闭控制窗口会请求取消并保留窗口直到任务终态 |
| 等待机制 | MainActor异步1ms轮询替代上游continuation/timeout；不阻塞主runloop。日志使用独立stderr适配器，不引入Ice完整app state |
| 菜单关闭 | 仅自有fixture的nonce/PID/菜单世代绑定RPC，由菜单本身cancelTrackingWithoutAnimation；核对ack、closedGeneration及菜单CG消失。历史官方Ice轮用自有控制器AXCancel；不能宣称本候选完整复刻了那一关闭通道 |
| 归位验证 | 同T/N窗口ID、实例及完整AppKit原帧；两份间隔120ms的状态，并核对T/H/N私有原帧和第三方status身份/bounds前后相等。只证明这些样本，不能证明所有时刻完整逻辑顺序 |
| 停止证据 | 一次性action/launch marker不清除，失败不重放；终态写入失败明确报告。post-intent与终态为进程内/末端记录，不是生产耐崩溃witness和recovery journal；possibleDown是保守路由状态，不证明真实按钮释放。未知结果需保留现场与责任 |

正常无重试闭环预计系统route调用14次：move 6、click 2、restore 6；不是18次，Ice点击没有PID再转送。失败路径次数另算并受200次硬上限。该数字目前由实现/离线路由推出，现场实际计数尚未产生。
