# 菜单栏收纳

## 使用

1. 在侧边栏选择 **菜单栏收纳**，点 **启用菜单栏收纳**。本工具会增加一个控制图标和一个 `│` 分隔符；初次启用后**默认展开，不自动藏图标**。菜单栏已满时，插件会在创建图标前为它们预留靠右的位置；原工具箱托盘图标会保留在分隔符右侧。关闭收纳功能后，下次启动会恢复原工具箱托盘图标的位置。
2. 控制图标必须留在分隔符右侧。可以设置「外面最多显示 N 个图标」并点「按数量整理」；应用会在**用户主动操作时**，从左到右把超出数量的可见图标逐个 ⌘-拖到分隔符左侧。也可自己按住 **⌘** 在原生菜单栏把图标拖过分隔符。
3. 点击 **授权屏幕录制**，按系统提示授权本应用；授权后可能要退出并重启应用。只有弹框采集图标缩略图时需要此权限。
4. 点控制图标或主界面 **收纳并打开** 会先按数量整理，再读取缩略图，全部收纳图标可读且控制图标仍可见时才收起。再次点控制图标可开/关第二排弹框；也可从仍可见的工具箱托盘菜单选 **打开收纳面板**。未授权或其它失败时仍会打开说明弹框，不会默默无响应。
5. 第二排上方是收纳区，下方是可见区；图标使用随浅色/深色外观变化的对比底色。点击收纳图标会展开并转发一次原生点击，点击可见图标会移入收纳区。可跨排拖放截图以移动**真实图标**，也可拖到同排其它图标上调整顺序；右键图标可选「移入/移出收纳区」，**打开工具箱** 可返回主界面。移动成功后重新采集并打开弹框，失败则保持展开。若系统不接受模拟 ⌘-拖动，可在原生菜单栏手动 ⌘-拖动。
6. 按 **⌃⌥⌘R** 可紧急展开；插件菜单/主界面也有 **展开并排列**。停用插件或退出工具箱时会先展开、再移除自家图标。显示器变化也会自动展开以防失控。

## 边界及失败保护

- 本版只针对 macOS 14–26 的旧菜单栏模型；低版本和 macOS 27 不启用隐藏区。当前这台机器是 macOS 15.7.4。
- macOS 没有公开的跨应用状态图标重排 API。弹框里的点击/拖放用辅助功能授权后的合成鼠标事件操作真实图标；未授权时显示原因，不反复弹系统授权提示。只有用户主动选择「权限与帮助 → 辅助功能权限」才请求系统授权。该功能不是系统原生菜单栏的完整替代，第三方图标可能拒绝或消失。
- 极度拥挤、刘海遮挡、受保护图标、其它显示器的图标可能无法捕获。本版遇到少一个缩略图就**不执行隐藏**，不会造出一个内容不全却仍藏起图标的弹框。
- 固定位置只影响本应用的三个图标，不修改其它应用的菜单栏位置。macOS 的菜单栏有硬容量限制，若其它图标仍挡住系统区域，固定位置也不能保证所有图标同时显示。
- 数量整理只处理**当前可见、可定位、可拖动**的状态图标；不会后台持续重排，也不能凭空找回已经被刘海或菜单项遮住的图标。遇到移不动的图标会停止并保持展开。要恢复已不可见图标，仍需原生 ⌘ 拖动、减少其它菜单项或使用外屏。具体机型和第三方图标的端到端效果需要人工验证。
- 不采集音频，不持久保存图标截图，不上传内容。仅在用户主动点击收纳时读取一次图标缩略图；展开、关闭或停用会清空内存缩略图。插件初次启用时不读取屏幕。
- 图标截图采用最多 4 路并发，失败仍保持展开。24 个本应用测试图标的本机样本中，串行采集约 1.57 秒、4 路并发约 0.91 秒（3 次运行的中位数）；这不是第三方图标、其它机器或长期运行的无性能问题保证。
- 如果控制图标或分隔符顺序错误、控制图标会被隐藏、屏幕录制未授权、任何待隐藏图标无法捕获，保持或恢复展开并显示错误。已隐藏图标的原生顺序由 macOS 保存；关闭本工具不会重新排序你的图标。

## 参考与许可

- [MenubarHide](https://github.com/junior-rj/menubar-hide)（MIT）：分隔符撑宽与第二排面板的产品思路；其文档说明菜单栏窗口可能属于 Control Center，且离屏图标可能无法截图。没有将其源码文件加入本项目。

- [Ice](https://github.com/jordanbaird/Ice)（GPL-3.0）：仅作产品功能对比，没有复制 GPL 源码。
