# 菜单栏收纳：安全手动版

## 使用

1. 在插件面板点 **启用收纳图标**。本工具会增加一个控制图标和一个 `│` 分隔符；初次启用后**默认展开，不自动藏图标**。
2. 按住 **⌘** 在 macOS 原生菜单栏拖动：想收纳的图标放在分隔符**左侧**，要保持显示的放在分隔符**右侧**。控制图标必须留在分隔符右侧。这相当于手动决定可见图标数量，并非自动按数字识别溢出项。
3. 点击 **授权屏幕录制**，按系统提示授权本应用；授权后可能要退出并重启应用。只有弹框采集图标缩略图时需要此权限。
4. 点控制图标或主界面的 **收进弹框**。插件先读取左侧图标的缩略图，全部可读、控制图标仍可见时才收起。再次点控制图标可开/关第二排弹框。
5. 想调整收纳顺序/移回外面：在弹框点 **展开菜单栏**，然后对**真实菜单栏图标**按住 ⌘ 拖动过分隔符。图标在弹框内是只读缩略图，不是可拖动的原生图标。
6. 按 **⌃⌥⌘R** 可紧急展开；插件菜单/主界面也有 **展开并排列**。停用插件或退出工具箱时会先展开、再移除自家图标。显示器变化也会自动展开以防失控。

## 边界及失败保护

- 本版只针对 macOS 14–26 的旧菜单栏模型；低版本和 macOS 27 不启用隐藏区。当前这台机器是 macOS 15.7.4。
- 不能使用公开 API 任意移动其他应用的图标；原生 ⌘ 拖动仍由用户完成。**不能直接在弹框里拖动、点击或操作其他应用的图标。**
- 极度拥挤、刘海遮挡、受保护图标、其它显示器的图标可能无法捕获。本版遇到少一个缩略图就**不执行隐藏**，不会造出一个内容不全却仍藏起图标的弹框。
- 这是用户选择哪些图标在分隔符左侧的手动收纳，不是自动识别并接管所有已经溢出、不显示的图标。若你需要完全可交互的弹框及自动重排，应单独评估辅助功能/输入合成权限与兼容性，不能假称此版本已具备。
- 不采集音频，不持久保存图标截图，不上传内容。仅在用户主动点击收纳时读取一次图标缩略图；展开、关闭或停用会清空内存缩略图。插件初次启用时不读取屏幕。
- 如果控制图标或分隔符顺序错误、控制图标会被隐藏、屏幕录制未授权、任何待隐藏图标无法捕获，保持或恢复展开并显示错误。已隐藏图标的原生顺序由 macOS 保存；关闭本工具不会重新排序你的图标。

## 参考与许可

- [MenubarHide](https://github.com/junior-rj/menubar-hide)（MIT）：分隔符撑宽与第二排面板的产品思路；其文档说明菜单栏窗口可能属于 Control Center，且离屏图标可能无法截图。没有将其源码文件加入本项目。
- [Hidden Bar](https://github.com/dwarvesf/hidden)（MIT）：原生 ⌘ 拖动跨分隔符的操作方式。
- [Ice](https://github.com/jordanbaird/Ice)（GPL-3.0）：仅作产品功能对比，没有复制 GPL 源码。

本项目代码仍按根目录 MIT 协议分发。Apple 系统框架和图标由系统提供，不是本项目再许可的素材。
