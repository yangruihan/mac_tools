# Ice 日常入口（2026-10-10）
正式安装：/Applications/MacTools.app，0.2.2 build9。

## 使用
1. 菜单栏收纳 -> 收纳图标…，无需开发诊断入口。
2. 点击对应图标的「打开」。没有目标选择器或「开始单轮」控制窗口。
3. 正常使用原应用；菜单请正常关闭，普通窗口可切换到其他应用。
4. 界面不再占用后等待15秒，图标回到原邻居同一侧。
5. 排列仍在屏幕顶部按住Command拖拽原图标，不是面板内拖放。
